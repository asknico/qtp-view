# locale

每个 app 使用的国际化可能不同，这里用于扩展国际化的功能，例如扩展 dayjs、antdv-next 组件库的多语言切换，以及 app 本身的国际化文件。

## 目录说明

- `index.ts`：国际化入口，注册各语言包并接入 vben 的 locale 体系
- `langs/`：语言包目录（zh-CN / en-US 等 JSON 文件）

## QTP 项目约定

- 业务文案优先直接使用中文；需要多语言支持的业务模块（如看板、账户与资金）在此扩展语言包
- 框架级文案（登录、菜单、按钮等）的语言包由 `packages/locales` 提供，本目录仅做 app 级覆盖与扩展
