# \_core

此目录包含应用程序正常运行所需的**基础视图**（框架级页面，与 QTP 业务无关），这些视图直接参与应用布局和登录链路。

| 子目录 | 说明 |
| :----- | :--- |
| `authentication` | 登录 / 注册 / 忘记密码等认证页面 |
| `fallback` | 403 / 404 / 500 等异常兜底页面 |
| `profile` | 个人中心（个人资料、修改密码、登录记录等，含 `components` 子组件） |
| `social-callback` | 第三方登录（OAuth）回调处理页 |

> 注意：请勿在此目录下添加业务页面。QTP 业务页面请放到 `views/dashboard`（看板中心）或 `views/accounts`（账户与资金）下。
