# 演示使用自行删除

框架自带的功能演示页面集合，**与 QTP 业务无关，可整体删除**。

## 目录内容

| 子目录 | 演示内容 |
| :----- | :--- |
| `dict` | 字典组件使用示例 |
| `menu` | 菜单权限控制示例 |
| `query` | 列表查询/表格查询示例 |
| `sse` | 服务端推送（SSE）消息示例 |
| `tinymce` | TinyMCE 富文本编辑器示例 |
| `tiptap` | Tiptap 富文本编辑器示例 |
| `upload` | 文件上传组件示例（含 `insert.sql` 演示数据） |
| `vxe` | vxe-table 可编辑表格示例 |
| `wechat` | 企业微信消息推送示例 |
| `other` | 接口加解密示例等杂项（含 `readme.md` 说明） |

## 删除步骤

1. 删除本目录（含全部子目录）
2. 同步删除后端菜单表中指向这些页面的菜单记录（菜单由 `getRouters` 动态下发）
3. 全局搜索确认没有其他文件 import 本目录下的组件（`hook.ts` 等可能被引用）
4. 若删除了 `sse`，注意确认系统内是否有依赖 SSE 的功能（如实时提醒）再决定

> 演示目录中的组件有时会被业务页面参考复用（如 `upload` 的上传 Hook），删除前可先浏览一遍。
